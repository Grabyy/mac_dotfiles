# macOS Dotfiles

Simple and minimal dotfiles for my **M1 Mac**.

This repository contains the configuration files I use for my terminal and development environment.

## What's included

* **Alacritty** — Terminal emulator
* **Neovim** — Text editor
* **tmux** — Terminal multiplexer

## Notes

These are personal dotfiles and are mainly intended for my own macOS setup.

Feel free to use anything here as a starting point and adapt the configuration to your own workflow.
