# OpenBSD Dotfiles

Simple and minimal dotfiles for my **OpenBSD** setup.

This repository contains the configuration files I use for my desktop, terminal, and development environment.

## What's included

* **CWM** — Lightweight X11 window manager
* **KSH** — Shell configuration
* **Xresources** — X11 application settings and appearance
* **xsession** — X session startup configuration
* **Neovim** — Text editor and development environment
* **Picom** — X11 compositor
* **.config** — Application configuration files
* **Puffy wallpaper** — OpenBSD wallpaper

## Setup

This configuration is built around a lightweight OpenBSD desktop using **CWM**, **X11**, and **Picom**, with **Neovim** as the main editor.

The goal is to keep the environment simple, fast, and easy to maintain.

## Notes

These are personal dotfiles and are mainly intended for my own OpenBSD setup.

Feel free to use anything here as a starting point and adapt it to your own workflow.
